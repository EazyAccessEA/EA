Work / Shopify tool · web app

Flintmere

A checker for Shopify food shops. It reads a shop's public catalogue and flags the barcodes that get Google Shopping listings disapproved.

Who for
UK food businesses that sell on Shopify
Built with
Next.js, Remix, Postgres, Hetzner
Live at
flintmere.com

What it does

Give it a shop's address and it reads the shop's public product data.

It checks whether each barcode passes the check-digit test, and whether titles and product details are consistent. A wrong barcode gets a Google Shopping listing disapproved. A missing one limits where the listing can show.

Smaller calls

We took out a number we couldn't back

An early version estimated how likely each listing was to be hidden. Google doesn't publish the rate that estimate depended on, so we removed it rather than guess.

Score what the shop controls

Shopify writes a shop's llms.txt file automatically, so the owner has little say over it. We cut how much it counts towards the score.
