What it does

It asks the questions an expert would ask, then hands back a sharper version of your task.

The task keeps the same scope. It gets a better method, better source material and a check that doesn't rely on the AI marking its own work. It's free and open source.

Smaller calls

Keep the task the size it was given

Looking back over our own past runs, most asked for something the user hadn't. Version 1.1 holds the task to the scope it was given.

Publish the test it didn't win

A blind test, planned in advance, found no clear difference between /deeper and a plain prompt. That result is published alongside the test it did well in.

Sign-ups keep almost nothing

The email list stores a scrambled version of each visitor's IP address, using a key that changes every day, and old entries are deleted every night.
