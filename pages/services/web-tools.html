Why a tool

What changes when a job moves out of spreadsheets and email into a tool built for it.

Before we build, we write down the job the tool has to do and agree it with you.

Done by hand now

  • Spreadsheets copied between people
  • The same checks repeated every week
  • Steps that only one person knows

With a tool

  • One place that holds the data
  • Checks that run on their own
  • The steps written into the tool
