# Five-second test

Run this before you create the ad. Test 5 people who run a small business, or who would choose a web designer for one: a shop owner, a trader, a family member with a side business. Avoid anyone who has already seen the ad or knows what it's for.

## How
1. On your phone, open `feed-1080.png` full width, at roughly the size of a Facebook post.
2. Say: "I'll show you something for five seconds, then ask you three questions."
3. Show it for five seconds by the clock, then put the phone away.
4. Ask these questions in this order, without hints, and write down their words:
   1. "What was that selling?"
   2. "Who was selling it: a big company, or someone else?"
   3. "If you wanted it, what would you do next?"
5. Then show it again with the primary text from `copy.md` underneath, and ask: "Is anything there you don't believe, or that's unclear?"

## Scoring

| Person | 1. Website? | 2. One person / small? | 3. Message on WhatsApp? | Doubts |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

Count an answer only if they give it without being prompted. "A website" counts; "something about a bakery" doesn't.

**Pass:** at least 4 of the 5 people get all three questions right.

**Fail, and fix before spending:**
- Anyone thinks it's selling bakery goods, an app, or WhatsApp itself.
- Two or more people can't say what they'd do next.
- The same doubt comes up twice.

## After launch
- **Success:** at least 3 real enquiries (a person asking about a site, not spam) from the £30.
- **Stop rule:** pause the ad after £15 spent with no conversations, or only spam.
- Write down the date, the amount spent, the number of conversations and the number of real enquiries each week.
